Privacidade

O Ritmo é um projeto de portfólio. Não existe cadastro, login nem servidor recebendo o que você registra.

Seus dados de saúde ficam no aparelho

  • Doses, peso, sintomas, água, alimentação e configurações são guardados no IndexedDB do navegador, só neste aparelho. Nada disso é enviado para lugar nenhum.
  • O backup (exportar/importar em Ajustes) gera um arquivo que fica com você.
  • Para apagar tudo, use Ajustes → Apagar dados (ou limpe os dados do site no navegador).

Estatísticas de uso (opcional)

Se aparecer um aviso de cookies, o site está configurado com o Google Analytics 4. Ele só é carregado se você clicar em Aceitar e conta apenas visitas e páginas abertas. Os dados de saúde nunca são enviados. Se você recusar, nada é carregado.

O Ritmo não usa ferramentas de gravação de sessão (como o Microsoft Clarity), justamente porque a tela mostra dados de saúde.

Aviso

O Ritmo ajuda a organizar o acompanhamento, mas não substitui a orientação do seu médico.
